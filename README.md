# TaskMaster
Projeto de lista de tarefas utilizando .Net, Angular e SQLite

Para executar o projeto no navegador, é necessário abrir o terminal na pasta api e rodar com o comando dotnet run e depois abrir um terminal na pasta angular e rodar com o codigo ng serve e acessar o localhostt que sera informado para abrir a lista de tarefas

*obs: cetifique-se que sua maquina tenha o .Net e o node.js instalado com suporte ao angular cli
